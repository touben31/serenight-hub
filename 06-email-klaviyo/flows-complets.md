## Configuration technique Klaviyo

- Domaine email dédié : contact@serenight.com (configurer SPF + DKIM)
- Double opt-in activé (RGPD France)
- Segmentation de base : acheteurs / non-acheteurs / abandons / inactifs 90j
- Suppression automatique des désabonnés
- Tests A/B sur les lignes d'objet dès 500 abonnés
