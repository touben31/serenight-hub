## ⚡ 5 Actions AVANT de construire Shopify

> ⚠️ Ces 5 étapes sont **bloquantes**. Ne pas dépenser 1€ avant qu'elles soient cochées.

- [ ] Commander échantillons chez **2 fournisseurs différents** et tester physiquement (60-120€)
- [ ] Vérifier le certificat **OEKO-TEX** sur oeko-tex.com avec le numéro exact du fournisseur
- [ ] Préparer les **pages légales complètes** (CGV, retours 30j, ML, RGPD, cookies)
- [ ] Confirmer **3 000€ de capital disponible** (hors stock initial)
- [ ] Créer **structure légale** (micro-entreprise ou SASU)
