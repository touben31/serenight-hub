## 1.3 ⚠️ RISQUE MARQUE — Analyse complète

### Ce qui a été trouvé

**"SERENITY"** (différent de "SERENIGHT") est utilisé par plusieurs marques de couvertures lestées :
- **WakeUp Serenity** → renommée **Dormeur®** (marque déposée) — France
- **Nectar Serenity Weighted Blanket** — USA
- **DreamCloud Serenity Weighted Blanket** — USA
- **Serenity** (référence SRBLK001) — disponible sur Amazon.fr

**"SERENIGHT"** : Aucune marque déposée trouvée dans le secteur textile/literie.

### Analyse du risque de confusion

| Critère | Analyse |
|---------|---------|
| Similarité visuelle | "SERENIGHT" vs "SERENITY" — terminaisons différentes (-night vs -ity) |
| Similarité phonétique | Se-re-NIGHT vs Se-re-NI-ty — sons distincts en prononciation |
| Secteur commun | ⚠️ Les deux dans la literie/couvertures lestées |
| Marques FR déposées | Dormeur® déposé — pas "Serenity" (l'ancien nom) |
| Risque d'opposition | 🟡 Faible-Moyen — les terminaisons sont assez distinctes |

### Verdict risque marque

> **SERENIGHT est suffisamment distinct de SERENITY pour être déposable.**
> La terminaison "-night" vs "-ity" crée une différence visuelle et phonétique réelle.
> Cependant, le secteur commun (couvertures) mérite prudence.
>
> **Action recommandée :** Déposer la marque SERENIGHT à l'INPI (Classes 20 + 35)
> **dès les premières ventes** (délai < 30 jours post-lancement).

### Vérification INPI obligatoire (5 minutes)

```
1. Aller sur https://data.inpi.fr/marques
2. Rechercher : "serenight"
3. Rechercher : "sereni" (pour voir les marques proches)
4. Vérifier Classes 20 (literie) et 24 (textiles)
5. Si aucun résultat → risque faible → procéder
```

### Vérification EUIPO (protection européenne)

```
1. Aller sur https://euipo.europa.eu/eSearch/
2. Onglet "Trade marks"
3. Rechercher : "serenight"
4. Rechercher : "serenity" + Classe 20 + Classe 24
5. Si aucun résultat Serenight → déposer marque UE dès M3
```

## 3.5 Procédure de vérification OEKO-TEX — Protocole exact

### Étape 1 — Demander le numéro au fournisseur

Message à envoyer avant de commander l'échantillon :

```
Please provide:
1. The exact OEKO-TEX Standard 100 certificate number for this product
   (format: XX XXX XXXXXX)
2. The name of the testing institute that issued the certificate
3. The expiration date of the certificate

I will verify this on oeko-tex.com before placing any order.
```

**Signal d'alerte :** Un fournisseur qui refuse de donner le numéro, qui tarde plus de 48h, ou qui donne un numéro vague → probablement pas certifié.

### Étape 2 — Vérification en ligne

```
1. Aller sur :
   https://www.oeko-tex.com/en/apply-here/oeko-tex-databases/label-check

2. Entrer le numéro de certificat dans le champ de recherche

3. Vérifier :
   ✅ Le numéro est valide et correspond au bon produit
   ✅ Le nom du fournisseur correspond exactement
   ✅ La date d'expiration est dans le futur
   ✅ La catégorie produit correspond (textile / literie)
   ❌ Si "not found" → certificat inexistant ou faux
   ❌ Si expiré → produit non certifié actuellement
```

### Étape 3 — Vérification physique à réception

```
Sur l'étiquette du produit reçu :
→ Chercher le logo OEKO-TEX (mouton blanc sur fond vert)
→ Vérifier que le numéro sur l'étiquette = numéro vérifié en ligne
→ Scanner le QR code (si présent) → doit mener vers oeko-tex.com

Si numéro absent sur l'étiquette → demander au fournisseur de l'ajouter
sur la production du stock (obligatoire pour vendre "OEKO-TEX certifié")
```

### Étape 4 — Test laboratoire indépendant (optionnel mais recommandé)

Si doute ou enjeux élevés :

```
Laboratoires accrédités en France :
- Bureau Veritas : bureauveritas.fr → Contact → Textiles
- SGS France : sgs.com/fr → Textiles et vêtements
- Intertek France : intertek.com/fr → Textiles

Coût : 200-400€ · Délai : 10-20 jours ouvrés
Test : Substances chimiques (formaldéhyde, métaux lourds, colorants azoïques)
→ Résultat = preuve indépendante en cas de litige avec la DGCCRF
```
