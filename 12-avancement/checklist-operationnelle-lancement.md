## BLOC 7 — TEST PRODUIT (J15-J20 · Après réception échantillons)

### Protocole de test échantillon (10 critères)

- [ ] **Peser** le produit à la réception — poids annoncé ±200g max (balance de cuisine)
- [ ] **Vérifier les billes** : secouer → silencieux = verre ✅ · bruyant = polypropylène ❌
- [ ] **Tester les coutures** : tirer fort sur chaque côté → aucune couture ne doit céder
- [ ] **Vérifier la répartition** : étaler à plat → billes uniformément distribuées sur toute la surface
- [ ] **Photographier** recto + verso + détail couture + étiquette OEKO-TEX → dossier qualité
- [ ] **Scanner QR code OEKO-TEX** → oeko-tex.com → numéro valide, non expiré ✅
- [ ] **Laver en machine** à 30° cycle délicat → vérifier : pas de déformation, billes bien réparties après
- [ ] **Sécher** à plat ou sèche-linge basse température → vérifier pas de retrait tissu
- [ ] **Dormir avec** pendant 3 nuits → test subjectif : sensation, chaleur, bruit, confort
- [ ] **Décision GO / NO GO** : si 8/10 critères validés → commander le stock initial

### Si GO → Commander le stock initial
- Quantité : **15 pcs × 3 SKUs = 45 pcs** (budget ~840€ + 280€ fret)
- Payer via **Alibaba Trade Assurance uniquement**
- Délai estimé : 20-28j fabrication + 10-15j livraison
