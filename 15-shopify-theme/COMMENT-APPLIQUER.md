# 🎨 THÈME HORIZON — CONFIGURATION SERENIGHT
> Appliquer ces fichiers via l'éditeur de code Shopify pour transformer le thème

---

## PROCÉDURE (5 minutes)

```
1. Shopify Admin → Boutique en ligne → Thèmes
2. Horizon → Actions → Modifier le code
3. Pour chaque fichier ci-dessous :
   - Trouver le fichier dans l'arborescence à gauche
   - Remplacer le contenu par le contenu du fichier GitHub
   - Enregistrer
```

## FICHIERS À MODIFIER

| Fichier GitHub | Fichier Shopify | Effet |
|---------------|----------------|-------|
| `settings_data.json` | `config/settings_data.json` | Couleurs Serenight |
| `templates-index.json` | `templates/index.json` | Homepage complète |
