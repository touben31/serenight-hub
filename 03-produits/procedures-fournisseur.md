### ÉTAPE 4 — PAIEMENT ÉCHANTILLON

```
RÈGLE D'OR : Ne jamais payer autrement qu'Alibaba Trade Assurance

Procédure :
1. Le fournisseur vous envoie une offre via Alibaba Trade Assurance
2. Vous la révisez (vérifier que les specs correspondent)
3. Vous payez via votre compte Alibaba (carte bancaire)
4. Le paiement est bloqué chez Alibaba jusqu'à confirmation de réception
5. Si le produit ne correspond pas → litige → remboursement possible

Budget échantillon : 30-80€ produit + 30-60€ frais de port DHL = 60-140€/fournisseur
Commander chez 2 fournisseurs = budget total ~120-280€
```

### PROCÉDURE VÉRIFICATION OEKO-TEX (Obligatoire avant tout GO)

```
ÉTAPE 1 — Récupérer le numéro
Format : XX-XXX-XXXXXX (ex : DE 123-456789)
Demander au fournisseur AVANT de commander l'échantillon.

ÉTAPE 2 — Vérifier en ligne
→ oeko-tex.com/en/apply-here/oeko-tex-databases/label-check
→ Entrer le numéro
→ Vérifier :
   ✅ Numéro valide et actif
   ✅ Nom fournisseur correspond
   ✅ Date d'expiration dans le futur
   ✅ Produit = "Home textiles" ou "Bedding"

ÉTAPE 3 — Vérifier sur l'étiquette physique
→ Le logo OEKO-TEX doit être imprimé sur l'étiquette du produit
→ Le numéro sur l'étiquette = le numéro vérifié en ligne

SIGNAUX D'ALARME :
❌ Fournisseur refuse de donner le numéro
❌ Numéro introuvable sur oeko-tex.com
❌ Numéro correspond à un autre produit ou fournisseur
❌ Certificat expiré depuis plus de 6 mois
→ Dans tous ces cas : changer de fournisseur immédiatement
```
